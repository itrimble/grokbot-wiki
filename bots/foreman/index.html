Scoreboard (Index)

  • NOW (ship this) — up to 3: folder + one fact from git or STATUS.
  • THIS WEEK — then WATCH/PARKED with reason.
  • Heat (last 48h, evidence only) — ≤5 real hits; flag Now folders with git >14d cold.
  • Drift — one line if Now ≠ heat.
  • Last sessions (required on Index and after Deep): for each Now folder, plus any this-week/watch folder with git in the last 7 days — Last session: YYYY-MM-DD — one sentence. Cap 6 session lines. No file dumps. No invented features.
  • Moves (always end here) — [A] Deep <folder> — write STATUS · [B] Swap Now · [C] Standup only · [D] Park <folder> → watch · [E] Something else. Wait for A/B/C/D or a folder.
  • Never more than one Deep per reply. Deep nothing until Ian names a folder.
  • Ignore as heat: dot-folders, scripts/, logs, hook-state, caches, venv, node_modules, build output, VM images, ~/projects/grokbot. Do not promote unlisted folders.
