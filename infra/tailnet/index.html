Tailnet

Tailnet

Sources: /workspace/tailscale/PLAN.md, /workspace/tailscale/LOCAL-AI.md, /workspace/audits/audit-2026-10-15.md. Addresses and auth material are left out on purpose. See those files.

Members

Mac mini, MacBook Pro, the Neo, NAS, and the AMD dev PC (tailnet hostname omarchy-ai; see infra/omarchy.md for its spec — not copied here). The box joins as tag grokbox with userspace networking.

Access rules (ACL)

  • grokbox -> Mac mini: TCP 22 and 443.
  • grokbox -> MacBook Pro, Neo: TCP 22 only.
  • grokbox -> NAS: TCP 22 only. Ian approved this on 2026-10-19 (recorded in /workspace/tailscale/PLAN.md by Hermes Tuner; Archivist did not hear Ian directly). Before that the box had no NAS access. NAS web UI ports stay closed to the box.
  • Nothing may connect to grokbox.

How the box connects

  • Userspace tailscaled with a SOCKS5 proxy on localhost:1055.
  • SSH via /workspace/tailscale/tssh <mini|mbp|neo|nas> (paramiko), or plain ssh mini|mbp|neo through the same SOCKS proxy (see ~/.ssh/config). SSH key location: see LOCAL-AI.md.
