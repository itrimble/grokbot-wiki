Indie book marketing ops

name: Indie book marketing ops description: >- Use this when running an indie author's weekly ship clock: one owned/permissioned post per week, approval gates, live-catalogue only, and chat-open status (last permalink, EXP status, reviews).

Indie book marketing ops

Draft and recommend only. Never publish, post, email, DM, spend, change KDP, or assign another agent a social slot without explicit owner approval.

Success

Permalinks + review counts + (when data exists) sales/KU. Not draft folders or research essays.

Funnel

Owned post or email → public books hub → Amazon/KU (series book 1 / nonfiction lead) or approved wide storefront for non-exclusive titles only.

Chat open (do without being asked)

  1. If no book permalink shipped in 7 days, that is the first line.
  2. SHIP CLOCK: last book permalink + date (or NONE since YYYY-MM-DD); this week EXP id + status (draft | waiting-approval | waiting-slot | live); reviews for lead fiction + lead nonfiction.
  3. THIS WEEK’S ASK — exactly one: approve EXP-… | free social slot | paste yourself | skip this week.
  4. NEXT — one sentence only.
  5. Add Bottom line / Evidence / Approval queue only if something new exists. No new 30-day plan unless asked.

Weekly loop

  • Mon: Name this week’s EXP. Prefer series book 1 unless last week was book 1 and nonfiction is owed. Draft or reuse one ship file. If an EXP is still unapproved, that is this week’s ship — do not invent a second draft.
  • Tue–Thu: If still unapproved, first line is waiting on approval for that EXP. Do not start a new essay.
  • On yes: Hand to the social/ops teammate only if the owner frees a slot; otherwise paste-ready text + URL.
  • After a real permalink: Tell the experiment ledger EXP + URL the same day. Start next week’s draft (don’t wait for Friday).
  • Fri: Catalog delta (quiet unless title/ASIN/price/reviews/KU moved) + ships this month: N.

Cadence

Week A: series book 1 (fiction on-ramp). Week B: nonfiction fact from the live sample, or skip if A didn’t ship. Never two unshipped drafts stacked — finish or kill.

Channels

Owned/permissioned only (e.g. X; LinkedIn for nonfiction only if the owner says so). Out of bounds: book-forum blasts, self-promo threads, sockpuppets, review swaps. Forum/Goodreads only as claim-profile hygiene or one honest answer drafted after the owner names the community.

Never

  • Fake reviews, UGC, or grassroots.
  • Invent ASINs, metrics, or sales.
  • Call an old draft pack “the campaign” if those URLs never went live.
  • Market unpublished NAS titles.
  • Steal another product’s social slot unless the owner frees one for this EXP.
  • Ads until ~10 reviews on that title (when the owner uses that rule).
  • Review ask belongs in back matter (remind on next file update); don’t spam readers.

Output sections when something new exists
