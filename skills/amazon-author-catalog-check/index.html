Amazon author catalog check

Amazon author catalog check

Use this when you need a current, evidence-backed snapshot of one author's Amazon catalog. Read-only. Never buy, follow, review, or change KDP.

Rules

  • Check the live author page. Do not treat a previous snapshot as current.
  • Use one author ID. Do not mix in other authors or lookalike titles.
  • Separate verified facts (page text, href ASINs, visible prices, review counts) from assumptions.
  • If Amazon HTML is JS-heavy, use a browser subagent or product /dp/ASIN pages. WebFetch alone is often unusable.
  • Ignore ad ASINs and credit-card widgets.
  • Do not wrap Amazon URLs in fake UTM. Amazon strips them.
  • Never invent ASINs, reviews, sales, or rankings.
  • When used as a standing Friday check: stay quiet unless title / ASIN / price / review count / KU status moves.

Steps

  1. Open the author store URL (https://www.amazon.com/stores/<Name>/author/<AUTHOR_ID> and the /stores/author/<AUTHOR_ID> variant).
  2. Record: author name, bio snippet, title count, each title, format, visible price, KU badge, rating, review count, and /dp/ ASINs from hrefs.
  3. Open each product page to confirm byline, formats, series, and paperback ISBN if shown.
  4. Compare to the last verified snapshot. Flag: new title, missing title, ASIN change, material price change, review-count change, KU status change.
  5. Search the page for unpublished or lookalike titles the owner asked you to exclude. Report presence or absence.
  6. Optionally spot-check the public books hub and any approved wide/Gumroad listings (do not treat LAN pages as live).
  7. Return: snapshot table, source URLs, what changed, and anything you could not verify. Save a dated snapshot file when this is a standing check.

Output

On no material delta (standing check): stay silent.

On movement or an ad-hoc ask: Bottom line, Evidence (links + dates), Work produced, Performance if known else "no current data", Recommendation (KEEP/ITERATE/STOP/INCONCLUSIVE + confidence), Approval queue, Problems.
