Grok Bot shop docs (Remnant Security)

Docs for Ian Trimble's Grok Bot shop. Maintained by Archivist. Source of truth: /workspace/grokbot-docs on the box. Copy target: ~/projects/grokbot on the Mac mini (see SYNC_QUEUE.md).

Map

  • ARCHITECTURE.md: diagrams of bots, box, Macs, tailnet, handoffs.
  • bots/: one file per bot.
  • skills/: shared skills index and SKILL.md copies.
  • infra/: box, Macs, tailnet, local AI, Apple dev.
  • routines.md: every scheduled routine (server authoritative).
  • diagrams/STYLE.md: house style for architecture diagrams (Ian via Atlas, 2026-10-19). First fleet map in /workspace/grokbot-preview/diagrams-house/ (not published).
  • decisions/: dated decision records.
  • Orchestration (Phase 0, approved by Ian 2026-10-17): Atlas keeps the board at /workspace/orchestration/BOARD.md on the box. Linked, not copied. See decisions/2026-10-17-box-control-plane.md.
  • OPEN-WORK.md: single master list of open work (waiting on Ian, in progress, waiting on other, done, stale).
  • CHANGELOG.md, SYNC_QUEUE.md.

Rules for these docs

  • No secrets, keys, tokens, passwords, or auth-related IPs. Point to file locations.
  • Document other bots. Never edit them.
  • No push to any remote without Ian's yes.
  • Server schedules beat local automation files when they disagree.

Approval rules (shop-wide)

Every bot asks Ian before posting, sending, DMs, deploys, DNS, spend, ASC writes, or deletes. Exceptions / nuances:

  • Expert Calls needs Ian's yes in his own words before any questionnaire, acceptance, client-manager reply or decline.
  • X Bookmarks may post up to about 5 disclosed competitor-complaint replies a day.
  • Learning to Sell may auto-post its blog series and post or reply publicly without per-post approval, after Ian's kickoff go (granted 2026-10-18). See decisions/2026-10-18-learning-to-sell.md.
  • Dev Diary: may post publicly on X (Ian, 2026-10-16 12:14 AM CT, reported by Atlas). Ian still approves main posts unless a standing rule says otherwise; Atlas handles other inbound social.
